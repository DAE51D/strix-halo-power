## What's new

- **Reset the power-history chart independently.** Configure → General now has a
  *Reset history graph* button alongside *Reset cost counter*. Clearing the
  rolling chart does not erase cumulative energy or cost; resetting the cost
  counter does not clear chart history.
- **The chart refreshes immediately after reset.** An already-open popup now
  updates as soon as the history reset completes instead of continuing to show
  the old chart until its next periodic refresh.

## Upgrade notes

The downloadable `.plasmoid` is the Plasma widget only. This release adds a
`ResetHistory` method to the D-Bus backend and bridge, so update the full stack
from the v1.3.0 source before using the new history-reset button:

```bash
sudo ./install.sh
```

If the v1.3.0 backend and bridge are already installed and you only need to
update the widget:

```bash
kpackagetool6 -t Plasma/Applet -u pmode-1.3.0.plasmoid
```

For a first-time widget install, use `-i` instead of `-u`. The full driver and
service stack is required; the widget package alone does not provide it.
