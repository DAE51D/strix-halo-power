## What's new

- **Total energy in the popup.** The stats row now shows lifetime energy next to
  cost: `total 3.36 kWh · cost $0.4372`.
- **Redesigned hover tooltip.** A dark card with one bar row each for power,
  temperature, fan speed and load, readable on both light and dark Plasma themes.
  Replaces the old tooltip, whose fixed grays clashed on light themes.
- Refreshed screenshots.

## Upgrade notes

This release changes the Plasma widget only; the driver, backend and bridge from
v1.3.0 are unchanged. To update an installed widget:

```bash
kpackagetool6 -t Plasma/Applet -u pmode-1.4.0.plasmoid
systemctl --user restart plasma-plasmashell.service
```

For a first-time widget install, use `-i` instead of `-u`. The full driver and
service stack (`sudo ./install.sh`) is required; the widget package alone does
not provide it.
